# Code of Conduct

This project follows the [Contributor Covenant, v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, focus on the work, and help
keep this a place people of any background want to contribute to.

## Scope

This applies to all project spaces — the GitHub repo (issues, PRs,
discussions, commit messages, code comments) and any chat or event held
under the project's name.

## Reporting

If you experience or witness behavior that violates the Code of Conduct,
please email the maintainer (the address is in the commit log) or use
GitHub's "Report content" flow. Reports will be handled confidentially.

Maintainers who do not uphold the Code of Conduct in good faith may be
temporarily or permanently removed from the project.
